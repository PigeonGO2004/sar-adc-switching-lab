# SAR ADC 切换逻辑可视化

交互展示理想全差分 SAR ADC 的 CDAC 结构、逐次比较、底板切换，以及顶板、共模和差分残差电压的变化。

## 使用

使用现代浏览器直接打开 `sar-preview.html`，无需安装或构建。

页面主体的样式、仿真逻辑和数据均已内嵌。辅助提示与图标运行库通过 CDN 加载。

## 功能

- 比较传统试探/撤销、Monotonic、对称 MCS、Tri-level 和 Vcm-based Monotonic 五种基本方案。
- 支持 3～10 bit，VREF 为 0.1～5 V，差分输入范围为 ±VREF。
- 差分输入可通过滑块或数值框设置；输入框中的数值为差分输入与 VREF 的比值。
- 使用上一步、下一步和过程滑块检查每个动作；控制栏可在滚动时吸附顶部。
- 高亮发生切换的电容、采样开关和正在判决的比较器。
- 可勾选电压曲线、调整波形高度，并查看比较记录、电容电压和方案对比表。

## 模型约定

- 理想电容、开关、参考电压与比较器，忽略寄生、失配、噪声和建立时间。
- 输入共模固定为 VREF/2；低、中、高参考分别为 0、VREF/2、VREF。
- 对于 N bit，差分满量程宽度为 2×VREF，1 LSB 为 2×VREF/2^N。
- 横轴表示操作顺序，不代表实际时间。
- 传统方案的首轮参考配置独立列出；每次比较后的撤销和下一位试探属于同一轮切换。末位判决后仅锁存输出码，CDAC 保留末次试探状态。

这些是五种方案的特定理想实现，用于理解和比较切换行为。
